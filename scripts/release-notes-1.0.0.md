# Snatch 1.0.0

First public release. Fast, native macOS GIF recorder.

## What's in 1.0.0

- ⇧⌘6 hotkey opens a region cropper anywhere on macOS.
- 8-handle resize, drag-to-move, remembers your last region.
- Records to GIF via gifski; sub-second stop-to-save on M-series.
- Menubar app (no Dock icon) with a Recent Recordings ▸ submenu.
- Esc cancels during selection or recording.
- Three scale presets (Retina / Standard / Compact).
- Saves the GIF to `~/Desktop/` and copies the file URL to your clipboard — paste straight into Slack, Discord, or Notes.

## Requirements

- macOS 14 (Sonoma) or later.
- Universal binary (Apple Silicon + Intel).

## Install

Download `Snatch-1.0.0.dmg`, open it, drag `Snatch.app` to `Applications`. Grant Screen Recording on first launch.
